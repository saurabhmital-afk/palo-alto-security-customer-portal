# Customer Portal

A self-service customer portal prototype for a fictional enterprise software company. It models how customers can review products, manage licenses, track orders, browse downloads, and configure new purchases without needing support intervention.

## What this project demonstrates

- customer account and dashboard UX
- self-service product configuration
- entitlement and license tracking
- order lifecycle and invoice visibility
- team and role management in a B2B product context

## Tech stack

- HTML
- CSS
- JavaScript
- CSV-driven data model
- Browser-based state simulation

## Run locally

```bash
cd customer-portal
npm start
```

or:

```bash
cd customer-portal
python3 -m http.server 8000
```

Then open: http://localhost:8000

## Features

- Product overview and detail pages
- Product configurator with pricing logic
- Order status tracking
- Downloads and entitlement management
- Team access and permissions
- Simulated support and account activity

## Project files

- `app.js` — application logic and UI rendering
- `index.html` — portal shell
- `data/` — product, invoice, license, and activity data
- `styles.css` — visual design and layout
